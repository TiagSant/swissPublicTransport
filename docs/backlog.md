# Backlog

Le backlog se trouve dans les **GitHub Issues** :

- [Toutes les issues ouvertes](https://github.com/TiagSant/swissPublicTransport/issues)
- [Milestones / sprints](https://github.com/TiagSant/swissPublicTransport/milestones)

Conventions :
- Libellé de l'issue : `US-xx` pour une user story, `TECH-xx` pour une tâche technique.
- Format d'une user story : *En tant que… je veux… afin de…*, puis les critères d'acceptation en cases à cocher.
- Labels : `user-story`, `tech`, `à valider` (livré, en attente de validation par le PO).
- Un milestone par sprint ; une pull request par sprint, qui référence ses issues (`Closes #n`).
